🎬 清华团队开源全球首个千亿级 MoE 视频模型 MAGI-2 Preview：114B 参数只激活 6B，成本仅主流 1/10
8月5—6日，由清华特奖得主曹越领衔的 Sand.ai 正式发布并开源 MAGI-2 Preview。这是全球首个开源千亿级 MoE 统一音视频生成模型，总参数 1140 亿，单次前向仅激活约 60 亿。它用统一单流架构同时生成画面与声音，在 Artificial Analysis 图生视频榜单排名第六，生成 10 秒 1080P 视频成本约 0.5 元，达到主流模型的约十分之一。
💡 视频生成终于也迈入了“千亿参数 + 稀疏激活”的 MoE 时代。对投资人来说，这意味着 AIGC 视频应用的推理成本正在被快速打下，广告、短剧、电商视频等商业化场景可能迎来一波“杰文斯悖论”式的需求爆发，利好算力租赁、云厂商和拥有垂直场景的公司。

🏆 MiniMax H3 登顶 Hugging Face：视频模型“斩杀线”又被抬高，2K 分辨率每秒不到主流 1/3
8月6日，MiniMax 正式开源新一代通用多模态生成模型 H3，在 Artificial Analysis 视频编辑评测榜和 Arena 图生视频排行榜均位列全球第一，Hugging Face 热度升至榜首，超过 DeepSeek V4 Flash。H3 首次统一理解文本、图像、视频、声音组成的多模态上下文，输出原生双声道音视频，最高支持 15 秒 2K 分辨率。2K 下每秒价格不到主流模型 1/3，768P 下不到 1/2。

🧠 东吴证券发布 AI SKILL：把选股因子、K 线形态、深度学习择时变成“可调用的数字员工”
8 月 4 日，东吴证券金工团队发布《AGENT 时代 SKILL 为核》专题报告，系统展示如何把已有投研成果“Skill 化”。覆盖三类量化场景：自然语言生成分子并自动 IC 评测、动态时间规整匹配历史相似 K 线、GRU 深度学习择时输出多空中性观点；并延伸到主动投研：标准化报告生成、深度研究框架、投资决策委员会、基金研究 SKILL（FundLab）等。其本质是让研究方法和数据接口变成可复用、可审计、可沉淀的“数字资产”。
💡 这不是“AI 炒股神话”，而是“投研流程的乐高化”——把数据获取、因子计算、报告生成、投决讨论拆成一个个可调用模块。对个人可转债研究者来说，这意味着你可以用 Qlib + Python + LLM 把自己的双低、溢价率、正股动量策略封装成 Skill，让 AI 每天自动跑一遍、出信号、写周报。

💻 Meta 首款 AI 编程智能体 Muse Code 亮相：异步后台 Agent + 可精确恢复，挑战 Claude Code 与 Codex
8 月 6 日，扎克伯格亲自宣布 Meta 首款 AI 编程智能体 Muse Code，由 Meta AI 负责人 Alexandr Wang 带队。它基于 Muse Spark 1.2 模型，最大亮点是“异步后台智能体”——在整个会话期间保持一组专门后台 Agent 持续存活，而不是为单个任务临时生成，避免重复探索代码库；任务足够大时会分发到独立子 Agent 并行处理，每个子 Agent 都在隔离的 git 工作树中。崩溃后还能从停止点精确恢复，所有调用都有本地事件日志可审计。
💡 Meta 这次不是做“另一个 Claude Code”，而是把重点放在长会话记忆和可审计性上。对量化研究者来说，如果你让 AI 跑一个持续数小时的可转债因子挖掘任务，最怕的就是中途崩溃或“黑箱操作”。Muse Code 的本地日志和断点恢复，恰好戳中了生产级 AI 编程的痛点。

📝 WorkBuddy 上线“人机双写”：AI 走出聊天框，坐进文档里一起干活
7 月 30 日，办公 AI 平台 WorkBuddy 推出“人机双写”功能，首次实现 AI 与用户在同一文档界面内实时协同编辑，兼容腾讯在线文档与本地 Office 文件。用户选中文字即可让 AI 修改、在 Excel 里框选数据即可让 AI 分析生成图表、在 PPT 页面指定区域即可让 AI 补充内容。据介绍，技术方案撰写可从 1 天缩短至几分钟，市场调研从 1 周压缩至一上午。

💭 今日思考

今天的关键词是“Agent 接管工作流”——Meta Muse Code 让后台 Agent 持续替你写代码，阿里千问办公让 AI 把一项完整工作做完，东吴证券把投研流程封装成可调用的 Skill，WorkBuddy 让 AI 坐进文档和你一起改……AI 正在从“回答问题”变成“执行任务”。

对可转债投资者来说，这意味着两件事：
第一，研究生产的边际成本还会再降一个数量级——以后跑一遍全市场转债评分、写月报、做回测，可能只是一句自然语言指令。信息差和算力差会加速消失。
第二，真正的稀缺资源会转向“工作流设计”和“判断质量”——谁更能把 AI 嵌入自己的决策链条，谁更能对 AI 出的信号保持独立判断，谁就更可能在这个新环境里活下来。

问题抛给你：如果你能把可转债投研里 80% 的重复劳动（数据更新、因子计算、报告撰写、图表生成）交给 AI Agent，你愿意把省下来的时间用来做什么？是深挖更多个券、优化仓位管理，还是干脆扩大覆盖范围？🤔
